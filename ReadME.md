# 🎉 PlayfulOutings

A responsive recreational outing platform designed to help users discover fun outdoor activities, picnic locations, and entertainment options. Built as a Semester 1 capstone project, PlayfulOutings focuses on delivering a modern, visually engaging, and user-friendly experience across desktop and mobile devices.

🌐 **Live Demo:** https://sem1-e-project.vercel.app/

---

## 📖 Overview

PlayfulOutings is a front-end web application that demonstrates responsive web design, interactive user interfaces, and modern styling techniques. The project was developed collaboratively from concept to deployment and showcases practical web development skills using HTML, CSS, and JavaScript.

---

## ✨ Features

- 🎨 Modern and responsive user interface
- 📱 Mobile, tablet, and desktop compatibility
- 🎥 Animated video background
- ⚡ Smooth navigation and interactive elements
- 🖼️ Well-organized layouts and visual content
- 🌐 Live deployment using Vercel

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Vercel (Deployment)
